Contexte

Dans un environnement de support informatique, les équipes doivent traiter des tickets d’incidents et gérer un parc de matériel informatique. Ce projet reproduit un cas réel d’entreprise afin d’analyser les problèmes récurrents et améliorer la qualité du support.

Objectifs

✓ Analyser les tickets support
✓ Identifier les problèmes récurrents
✓ Calculer des KPI (temps, volume)
✓ Visualiser les données
✓ Comprendre la charge du support IT
✓ Créer des insights métier

Déroulement du projet

1. Création des données

Génération de datasets tickets et parc informatique.

2. Chargement Python

Import des données avec Pandas dans Jupyter Notebook.

3. Analyse exploratoire

Étude des catégories, priorités et volumes de tickets.

4. KPI & Visualisation

Création de graphiques avec Matplotlib.

5. Insights métier

Identification des problèmes principaux (ex: Wifi, priorités).
