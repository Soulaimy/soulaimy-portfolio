Contexte

Je souhaitais disposer d'un espace professionnel regroupant mes compétences, mes projets et mon parcours. Ce projet m'a également permis d'apprendre GitHub, Git et le déploiement d'applications web.

Objectifs

✓ Présenter mon profil
✓ Héberger mes projets
✓ Maîtriser GitHub
✓ Déployer avec Vercel
✓ Créer une identité professionnelle
✓ Construire un portfolio évolutif
